# Аренда PS5 — что внедрить (опрос владельца, с 27.11)

Цель: раздел аренды работает как отдельный бот для аренды; брат подключён (видит CRM клиентов, доходы, расходы); уведомления в рабочую группу с братом.
Порядок: 20 вопросов по одному → ответы сюда → задачи в docs/tasks.md → старт по «31».

## Ответы
1. Бот: ТОТ ЖЕ @finanstopbot (не плодить ботов). Брат по своему Telegram ID видит только раздел «Аренда» (свой отдельный раздел с братом).
2. Брат в боте ТОЛЬКО мониторит (смотрит), не записывает. Для аренды будет своё отдельное меню; разделы владелец перечислит.
3. РЕШЕНИЕ: ВТОРОЙ отдельный бот для аренды (тот же сервер и данные, связан с финансовым ботом). Зачем:
   - бизнес-консультант / коуч в рабочей группе с братом;
   - сохраняет договоры (фото, которые присылает владелец) за каждым клиентом → CRM;
   - считает доходы и расходы аренды;
   - расписывает задачи — владельца и брата;
   - максимально всё транслирует брату.
4. ИТОГ (владелец передумал): пока ВСЁ в этом же боте @finanstopbot. Владелец записывает как сейчас; бот транслирует брату.
   Брат в боте видит: текущие сделки (заказы), доходы, расходы аренды, сколько осталось до возврата вложений.
   (Второй бот-консультант — отложен, идеи из п.3 сохраняем на будущее.)
5. Уведомления по аренде (новый клиент, оплата, возврат и т.п.) — в РАБОЧУЮ ГРУППУ с братом (бота добавить в группу).
6. События в группу (владелец «начинай» — включены все): оплата/продление, бронь (предоплата), залог взят/возвращён, заказ закрыт, расход аренды, перевод брату; к каждому — «💪 Брату: к переводу X / всё переведено». Итоги дня/недели — позже (этап 7).
СДЕЛАНО 27.11: брат = строка «Telegram ID: брат» в Настройках → только просмотр: меню 🎮 АРЕНДА PS5 (доходы, расходы, прибыль, его доля) + 📋 Сделки, 📈 Доходы, 📉 Расходы, 💼 Вложения. Группа: владелец пишет /group в группе → DO rentGroup.
Нужно от владельца: ID брата (брат пишет боту /start → /seen) и добавить бота в рабочую группу + /group там.
7. (А) Отдельная Google-таблица ТОЛЬКО по аренде (сделки, клиенты, доходы, расходы, доля брата); брату доступ только к ней, личные финансы не видит. Кнопка «📄 Таблица» в Аренде → на неё.
8. (А) Таблица аренды обновляется сразу: бот дописывает каждую запись аренды (оплата, бронь, залог, расход) одновременно с главной таблицей.
9. Листы таблицы аренды: Сделки (клиент, приставка △✕□, даты, оплата, залог, статус), Доходы, Расходы, Итог (прибыль, доли 60/40, переведено брату, возврат вложений). Владелец: «подходит».
10. (А) О клиенте — только значок приставки (△✕□), имя/телефон/фото не записывать.
11. (А) Срок аренды: при оплате бот спрашивает «до какого числа?»; в день окончания 9:00 — напоминание владельцу и в группу «Сегодня у △ заканчивается аренда — продлевает или сдаёт?».
12. (Б) Напоминание об окончании — один раз («я в любом случае отвечу»).
13. (А) Кнопки в напоминании: «🔄 Продлевает» (сумма + новый срок) и «✅ Сдал приставку» (залог: вернул / удержал часть → закрыть сделку).
