# Аренда PS5 — что внедрить (опрос владельца, с 27.11)

Цель: раздел аренды работает как отдельный бот для аренды; брат подключён (видит CRM клиентов, доходы, расходы); уведомления в рабочую группу с братом.
Порядок: 20 вопросов по одному → ответы сюда → задачи в docs/tasks.md → старт по «31».

## Ответы
1. Бот: ТОТ ЖЕ @finanstopbot (не плодить ботов). Брат по своему Telegram ID видит только раздел «Аренда» (свой отдельный раздел с братом).
2. Брат в боте ТОЛЬКО мониторит (смотрит), не записывает. Для аренды будет своё отдельное меню; разделы владелец перечислит.
3. РЕШЕНИЕ: ВТОРОЙ отдельный бот для аренды (тот же сервер и данные, связан с финансовым ботом). Зачем:
   - бизнес-консультант / коуч в рабочей группе с братом;
   - сохраняет договоры (фото, которые присылает владелец) за каждым клиентом → CRM;
   - считает доходы и расходы аренды;
   - расписывает задачи — владельца и брата;
   - максимально всё транслирует брату.
