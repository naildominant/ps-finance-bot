# PS Finance bot

Telegram-бот учёта финансов (ТЗ: docs/TZ.pdf). Решения владельца и стартовые остатки: docs/start.md.

Схема как у ПОСТИКА, но отдельно: Cloudflare Worker `psfinance` + KV, Whisper (Workers AI) для голосовых,
Claude API для разбора текста и фото, Google Таблица через Apps Script (скрипт в самой таблице).

Этапы: 0 подготовка · 1 таблица · 2 текст · 3 голос и фото · 4 типы и остатки · 5 правила денег · 6 пользователи · 7 автосообщения · 8 пробная неделя.
